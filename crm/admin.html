Importer des prospects

Collez le résultat JSON de votre recherche. Les établissements arrivent au statut « À visiter », soit dans le pool commun où tous les commerciaux peuvent les réserver, soit directement dans le portefeuille d'un commercial.

Le pool commun est le mode conseillé : chaque commercial y pioche lui-même, dans la limite de son quota hebdomadaire. Une entrée peut forcer un commercial précis via un champ « commercial » (e-mail ou nom) — cette attribution nominative ne consomme pas de quota.
